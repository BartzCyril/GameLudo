ルドーの序盤は、**すべてのコマが拠点にあり、コマを出すには6が必要**です。誰のコマもまだ出ていない間は、各プレイヤーは1ターンに最大3回サイコロを振れます。最初に6を出した人がコマを出し、もう一度振って進みます。ゲームの始まり方をステップごとに見ていきましょう。

## 1. 色を選ぶ

各プレイヤーは色を選びます。Gameludoでは黄、緑、ピンク、水色の4色です。それぞれ4つのコマを持ち、盤の同じ色の角にある拠点に置きます。拠点の隣にある同じ色のスタートマスが、コマがコースに入る場所です。

## 2. 先攻の決め方

ルールはシンプルです。**全員がサイコロを1回振り、いちばん大きい目を出した人が先攻**です。

複数のプレイヤーが最大の目で並んだ場合は、**その人たちだけが振り直します**。他の人は先攻決めから外れます。**勝者が1人になるまで**繰り返します。

> 例：緑が5、ピンクが6、水色が6、黄が2を出しました。ピンクと水色が6で同点なので、この2人だけが振り直します。ピンクが3、水色が4：**水色が先攻**です。

小さい目での同点は関係ありません。振り直しが必要なのは、最大の目での同点だけです。

その後は勝者から**時計回り**に進みます。

## 3. 6を出すチャンスは最大3回

初心者がいちばん驚くルールがこれです。**コマは6を出したときだけ拠点から出られます**。

序盤が長引かないように、まだ誰のコマも出ていない間は、各プレイヤーに**1ターン3回のチャンス**があります。

- サイコロを振る
- 6が出たら、コマを1つ出す
- 出なければもう一度振る（最大3回）
- 3回振っても6が出なければ、次のプレイヤーの番

## 4. 最初のコマと最初の一手

6が出たら：

1. 拠点から**コマを1つ出し**、コースの最初の空いているマスに置きます
2. **もう一度サイコロを振ります**
3. 出た目の数だけ**そのコマを進めます**

6が出ると続けて2回動けます。ゲームの中でも大事な瞬間のひとつです。

## 5. 他のプレイヤーは1ターン1回

誰かのコマが盤上に出ると、全員のルールが変わります。**他のプレイヤーは、まだコマが出ていなくても、1ターンに1回しか振れません**。

最初にコマを出した人は**一時的に有利**になります。相手が6を待っている間に先へ進めるからです。ただし、コースに1つだけのコマは狙われやすいので、その有利はすぐに消えます。相手のコマの取り方は、[ゲーム中のルール](@gameplay)で解説しています。

## ゲーム開始のルールまとめ

| 段階 | 内容 |
| --- | --- |
| 色を選ぶ | 各プレイヤー4つのコマを拠点に置く |
| 先攻 | いちばん大きい目。同点なら同点の人だけ振り直し |
| 誰もコマを出していない間 | 6を狙って1ターン最大3回 |
| 6が出たら | コマを出し、もう一度振って進む |
| その後 | コマが盤上にない人も1ターン1回 |

## 上手に始めるコツ

- **焦らない**：6が出る確率は1回ごとに6分の1です。3回のチャンスで確率は上がりますが、保証はありません。
- **先を読む**：最初のコマが出たら、相手のコマの位置を確認しましょう。[攻めの攻略](@offensive)と[守りの攻略](@defensive)が、どのコマを動かすか決める助けになります。
- **ゴールを知っておく**：目標は4つのコマをすべてゴールレーンに入れること。方法は[ゲーム終盤のルール](@end)で解説しています。

ゲームの始め方がわかったら、[無料でルドーをオンラインプレイ](@play)して、最初の6を出してみましょう！
